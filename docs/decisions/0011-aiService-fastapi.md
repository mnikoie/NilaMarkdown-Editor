# 0011 — سرویسِ AI / پردازشِ فارسی: Python + FastAPI

- **تاریخ:** ۱۴۰۵/۵/۲۹
- **وضعیت:** ✅ پذیرفته‌شده

## زمینه

پردازشِ متنِ فارسی و کارهای AI کجا انجام شود؟

## تصمیم

**Python + FastAPI** انتخاب شد.

دلیل‌ها:
- کتابخانه‌های پردازشِ زبانِ فارسی (Hazm، ParsBERT) اینجا زندگی می‌کنند
- سندِ خودکارِ API
- سریع و async

عیب‌هایی که پذیرفته شد:
- یک زبانِ دوم در پروژه یعنی دو محیطِ نصب
- استقرارش از سرویسِ Node جداست

## گزینه‌های دیگر

| گزینه | مزیت | چرا انتخاب نشد |
|---|---|---|
| Node.js (همان زبانِ بک‌اند) | یک زبان برای کلِ پروژه — یک محیطِ نصب و یک زنجیرهٔ استقرار | کتابخانه‌های پردازشِ زبانِ فارسی در پایتون خیلی قوی‌ترند؛ برای کارِ سنگینِ عددی مناسب نیست |

## پیامدها

  تغییرها پس گرفته می‌شوند، نه بیشتر و نه کمتر.
