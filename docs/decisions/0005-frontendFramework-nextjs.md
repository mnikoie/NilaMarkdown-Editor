# 0005 — فریم‌ورکِ فرانت: Next.js

- **تاریخ:** ۱۴۰۵/۵/۲۹
- **وضعیت:** ✅ پذیرفته‌شده

## زمینه

رابطِ کاربری با چه چیزی ساخته شود؟

## تصمیم

**Next.js** انتخاب شد.

دلیل‌ها:
- بزرگ‌ترین اکوسیستم و بیشترین منبعِ آموزشی
- امکاناتِ آمادهٔ زیاد

عیب‌هایی که پذیرفته شد:
- به Vercel متمایل است
- پیچیدگیِ درونیِ بیشتر
- بیلدِ کندتر

## گزینه‌های دیگر

| گزینه | مزیت | چرا انتخاب نشد |
|---|---|---|
| React Router v7 (framework mode) | رندرِ سمتِ سرور با روتینگِ ساده | اکوسیستمِ کوچک‌تر از Next.js؛ منابعِ آموزشیِ کمتر |
| Vite + React (SPA) | ساده‌ترین راه برای یک برنامهٔ تک‌صفحه‌ای | رندرِ سمتِ سرور ندارد — برای SEO باید خودت کاری کنی؛ روتینگ و داده‌گیری را خودت باید بچینی |

## پیامدها

- فایل‌ها و وابستگی‌هایی که این تصمیم اضافه کرد، در همان کامیتِ این تصمیم‌اند.
- برگشت از این تصمیم با `git revert` همان کامیت انجام می‌شود — دقیقاً همان
  تغییرها پس گرفته می‌شوند، نه بیشتر و نه کمتر.
- `project.config.json` فقط **قصد** را ثبت می‌کند. نصب‌بودنِ واقعی جدا و با
  مدرک بررسی می‌شود (لینکِ node_modules، خروجیِ docker compose ps، وجودِ .venv).
