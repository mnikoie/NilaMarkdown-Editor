# ۰۰۳۲ — یک حالتِ تاشدن برای کارتِ ساختاری و Outline

- **تاریخ:** ۱۴۰۵/۰۵/۳۰
- **وضعیت:** پذیرفته‌شده؛ بندِ «state مستقلِ کارت‌ها» در ۰۰۲۹ را برای
  directiveهای ساختاری جایگزین می‌کند

## زمینه

directive ساختاری مانند «ماده» و «تبصره» هم یک `OutlineNode` است و هم با
`MarkCardView` رندر می‌شود. افزونهٔ fold محتوای آن را با Decoration پنهان
می‌کرد و NodeView نیز همان محتوا را با `display` می‌بست. این دو state مستقل
سه خرابیِ قابل‌مشاهده ساختند:

- سربرگِ کارت باز می‌شد ولی خلاصهٔ «بلوک پنهان» داخلش باقی می‌ماند؛
- Outline باز بود ولی کارت در متن بسته می‌ماند، یا برعکس؛
- فقط دکمهٔ کوچکِ فلش واکنش داشت و کلیک روی خودِ سربرگ در Chrome بی‌اثر بود.

## تصمیم

برای directiveهایی که `anchor: true` دارند، شناسهٔ ساخته‌شده با
`buildOutline` روی DOM کارت با `data-fold-id` قرار می‌گیرد. state افزونهٔ
`foldPlugin` منبعِ حقیقتِ ساختاری است و NodeView فقط نمای همان state را
نگه می‌دارد:

1. تغییرِ کارت رویدادِ `tm-card-fold-change` با `id`، موقعیت و حالتِ مطلوب
   می‌فرستد؛ پوسته همان گره را در `foldPlugin` تغییر می‌دهد.
2. تغییر از Outline یا ناوبری، رویدادِ `tm-set-fold` را فقط به کارتِ دارای
   همان شناسه می‌فرستد.
3. فرمان‌های «بازکردن همه» و «بستن همه» افزونه، فهرست‌ها و همهٔ NodeViewها
   را صریح تنظیم می‌کنند و از محدودیتِ آکاردئون عبور می‌کنند.
4. کلِ سربرگ hit area تاشدن است؛ دکمهٔ واقعی با `aria-expanded` و
   Enter/Space برای صفحه‌کلید باقی می‌ماند.

شناسه‌های موقعیتی برای هر نمونهٔ immutable از سند cache می‌شوند تا
NodeViewهای متعدد `buildOutline` را برای یک سند تکرار نکنند. هیچ state یا
شناسه‌ای واردِ مدلِ ProseMirror یا Markdown نمی‌شود.

directiveهای غیرساختاری که `anchor` ندارند همچنان state محلیِ NodeView
دارند؛ چون در Outline متناظر نیستند، همگام‌کردنشان معنایی ندارد.

## گزینه‌های دیگر

| گزینه | مزیت | چرا رد شد |
|---|---|---|
| حذفِ directiveها از `foldPlugin` | تنها یک پنهان‌سازی در DOM | Outline دیگر state و خلاصهٔ یکپارچه نداشت و `foldAll` ناقص می‌شد |
| حذفِ state از NodeView | ساده‌ترشدنِ کارت | بدنه و آکاردئونِ کارت‌های غیرساختاری بدون مالک می‌ماند |
| نگهداریِ دو state بدون همگام‌سازی | کد کمتر | همان واگرایی و «بلوک پنهان» را بازتولید می‌کند |
| تبدیلِ state به صفتِ سند | همگام‌سازی خودکار با تراکنش | حالتِ نمایش وارد Markdown و undo می‌شد و قاعدهٔ رفت‌وبرگشت را می‌شکست |
| کلیک‌پذیرکردنِ `div` با نقشِ button | hit area بزرگ | دکمهٔ تودرتوی نامعتبر و مدلِ فوکوس مبهم می‌ساخت؛ سربرگ فقط hit area کمکی ماند |

## پیامدها

- ماده و تبصره از Outline و متن در هر دو جهت دقیقاً با هم باز و بسته می‌شوند.
- پس از بازشدنِ کارت، خلاصهٔ جعلیِ «بلوک پنهان» باقی نمی‌ماند.
- کلِ سربرگ با موس کار می‌کند و دکمهٔ فلش با صفحه‌کلید و صفحه‌خوان معتبر است.
- تستِ اختصاصیِ fold روی Chromium، Chrome واقعی، Edge واقعی، Firefox و
  WebKit اجرا می‌شود و فایل واقعیِ بخشنامه نیز در همان ماتریس پیمایش می‌شود.
