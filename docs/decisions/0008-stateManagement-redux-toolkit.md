# 0008 — استیتِ سراسری: Redux Toolkit

- **تاریخ:** ۱۴۰۵/۵/۲۹
- **وضعیت:** ✅ پذیرفته‌شده

## زمینه

داده‌ای که چند صفحه لازمش دارند کجا بماند؟

## تصمیم

**Redux Toolkit** انتخاب شد.

دلیل‌ها:
- ساختارِ مشخص و یکدست برای تیم
- ابزارِ عیب‌یابیِ عالی (تاریخچهٔ تغییرات)
- اکوسیستمِ بزرگ

عیب‌هایی که پذیرفته شد:
- کدِ بیشتری می‌خواهد
- برای پروژهٔ کوچک زیادی است

## گزینه‌های دیگر

| گزینه | مزیت | چرا انتخاب نشد |
|---|---|---|
| Zustand | خیلی کم‌حجم و ساده | برای پروژهٔ خیلی بزرگ ساختارِ سخت‌گیرانه‌ای تحمیل نمی‌کند؛ ابزارِ عیب‌یابی‌اش از Redux ضعیف‌تر است |

## پیامدها

- فایل‌ها و وابستگی‌هایی که این تصمیم اضافه کرد، در همان کامیتِ این تصمیم‌اند.
- برگشت از این تصمیم با `git revert` همان کامیت انجام می‌شود — دقیقاً همان
  تغییرها پس گرفته می‌شوند، نه بیشتر و نه کمتر.
- `project.config.json` فقط **قصد** را ثبت می‌کند. نصب‌بودنِ واقعی جدا و با
  مدرک بررسی می‌شود (لینکِ node_modules، خروجیِ docker compose ps، وجودِ .venv).
