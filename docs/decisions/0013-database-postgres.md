# 0013 — دیتابیس: PostgreSQL

- **تاریخ:** ۱۴۰۵/۵/۲۹
- **وضعیت:** ✅ پذیرفته‌شده

## زمینه

داده کجا ذخیره شود؟

## تصمیم

**PostgreSQL** انتخاب شد.

دلیل‌ها:
- رابطه‌ای و قوی، با پشتیبانیِ JSON
- جستجوی متنی داخلی دارد
- بسیار پایدار

عیب‌هایی که پذیرفته شد:
- تنظیمش از MySQL کمی سخت‌تر است

## گزینه‌های دیگر

| گزینه | مزیت | چرا انتخاب نشد |
|---|---|---|
| MySQL | رایج‌ترین، میزبانیِ ارزان و فراوان | امکاناتِ پیشرفتهٔ کمتر از Postgres؛ پشتیبانیِ JSON ضعیف‌تر |
| MongoDB | شکلِ داده از قبل تعریف‌شده لازم ندارد | تراکنش و join مثلِ دیتابیسِ رابطه‌ای قوی نیست؛ بی‌انضباطیِ شکلِ داده به‌مرور دردسر می‌شود |
| MariaDB | شاخهٔ آزادِ MySQL، با همان ابزارها و همان دستورها | در بعضی جزئیات از MySQL جدا شده و ۱۰۰٪ یکسان نیست؛ میزبان‌های ابری کمتر مستقیم پشتیبانی‌اش می‌کنند |
| SQLite | هیچ سروری لازم ندارد — یک فایل است | برای نوشتنِ همزمانِ چند کاربر ساخته نشده؛ روی چند سرور اصلاً کار نمی‌کند |

## پیامدها

- فایل‌ها و وابستگی‌هایی که این تصمیم اضافه کرد، در همان کامیتِ این تصمیم‌اند.
- برگشت از این تصمیم با `git revert` همان کامیت انجام می‌شود — دقیقاً همان
  تغییرها پس گرفته می‌شوند، نه بیشتر و نه کمتر.
- `project.config.json` فقط **قصد** را ثبت می‌کند. نصب‌بودنِ واقعی جدا و با
  مدرک بررسی می‌شود (لینکِ node_modules، خروجیِ docker compose ps، وجودِ .venv).
