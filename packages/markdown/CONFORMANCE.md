# گزارش انطباق Markdown

آخرین اجرا: ۲۸ اوت ۲۰۲۶

## مجموعه‌های رسمی

- CommonMark 0.31.2: `https://spec.commonmark.org/0.31.2/spec.json`
- GFM extensions از پیاده‌سازی مرجع GitHub: `https://raw.githubusercontent.com/github/cmark-gfm/master/test/extensions.txt`

فرمان بازتولید:

```bash
pnpm --filter nila-markdown conformance
```

اسکریپت نسخهٔ دقیق منبع‌ها را pin کرده، پکیج را build می‌کند و همهٔ مثال‌ها
را مستقیم از منبع رسمی می‌گیرد. شکست parse باعث exit code ناموفق می‌شود.

## نتیجه

| مجموعه | کل | parse بدون خطا | خروجی پایدار پس از بار دوم | سورس عیناً یکسان | HTML معنایی همسان |
|---|---:|---:|---:|---:|---:|
| CommonMark 0.31.2 | 652 | 652 (100٪) | 597 (91.6٪) | 191 (29.3٪) | 456 (69.9٪) |
| GFM extensions | 30 | 30 (100٪) | 29 (96.7٪) | 5 (16.7٪) | 6 (20٪) |

«سورس عیناً یکسان» معیار سخت‌گیرانهٔ بایتی است و انتظار نمی‌رود برای همهٔ
مثال‌های رسمی برقرار باشد؛ serializer عمداً شکل متعارف خود را برای ساختارهای
بدون metadata نگه می‌دارد. معیار مهم‌تر برای ویرایشگر، پایداریِ بار دوم است:
بعد از یک ذخیره، ذخیرهٔ دوباره نباید Diff تازه بسازد.

«HTML معنایی همسان» خروجی `exportHtml` را با HTML مرجع مقایسه می‌کند. در
مقایسه class/id/rel و wrapperهای `thead/tbody` نادیده گرفته می‌شوند، اما
تفاوت واقعیِ ساختار و متن حساب می‌شود. امتیاز GFM پایین‌تر است چون exporter
این پروژه برای سند حقوقی و HTML مستقل ساخته شده و هنوز قرارداد دقیق HTML
مرجع GFM—به‌ویژه جدول، footnote و tag filter—را هدف نگرفته است.

## فاصله‌های شناخته‌شده

- CommonMark: موارد ناپایدار عمدتاً Backslash Escape، چند حالت مرزی Setext،
  fenceهای خاص، تعریف لینک و ترکیب‌های پیچیدهٔ emphasis هستند.
- GFM: یک حالت autolink پس از بار دوم هنوز نرمال‌سازی تازه دارد.
- جدول‌های GFM از نظر محتوای سلول پشتیبانی می‌شوند، اما HTML صادرشده دقیقاً
  همان wrapper و attributeهای مرجع GitHub را تولید نمی‌کند.
- raw HTML تحت سیاست امنیتی `escape/sanitize/raw` است؛ در نتیجه حالت امن
  عمداً با خروجی خام مرجع یکسان نیست.

## سطح تضمین محصول

1. همهٔ 682 مثال رسمی بدون crash یا حذف کل سند parse می‌شوند.
2. fixtureهای حقوقی پروژه و نحوهایی که README صریحاً «حفظ شکل» اعلام کرده
   است باید رفت‌وبرگشت عیناً یکسان داشته باشند و در تست واحد fail-fast هستند.
3. برای بقیهٔ CommonMark/GFM فعلاً حفظ معنا هدف اصلی است؛ ادعای انطباق 100٪
   HTML یا حفظ بایتی سورس داده نمی‌شود.
